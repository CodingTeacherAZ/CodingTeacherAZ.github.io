Mini PD Artifacts

Using Formative Data to
Adjust Instruction in Real Time

Teachers learn to identify patterns in student responses and make immediate, targeted instructional adjustments — shifting from reactive to evidence-driven practice.

Audience CTE instructors, mixed experience levels
Duration 45 minutes
Format Collaborative workshop with individual apply phase
Objective Teachers analyze student data and produce one targeted instructional response they can implement the next day
Grounded in Adult Learning Theory — immediate application, relevant context
Structure of Session
Phase 01 — Model
Demonstrate the strategy

Facilitator analyzes a real student error dataset live — naming the pattern, interpreting the cause, and modeling a targeted instructional decision aloud.

0 – 10 min
Phase 02 — Analyze
Examine example data

Teachers review a second dataset in pairs — identifying the primary error type, estimating how many students are affected, and naming the likely root cause.

10 – 25 min
Phase 03 — Apply
Adapt to their context

Each teacher selects data from their own class or program, uses the same protocol, and drafts one concrete instructional adjustment they will implement next session.

25 – 38 min
Phase 04 — Share
Discussion and reflection

Two teachers share their response plans. Group names what the adjustments have in common — surfacing a transferable principle rather than a subject-specific fix.

38 – 45 min
Sample Activity — The Core Task
Facilitator Prompt
Data Pattern Analysis + Instructional Planning
  • 01 Review the student error set provided. Look at frequency, not individual responses — you're finding a pattern, not grading.
  • 02 Identify the primary error type affecting the most students. Write one sentence naming what the pattern reveals about student understanding.
  • 03 Plan one instructional adjustment you will make in your next class — be specific: what you will add, remove, or replace, and why.
What Teachers Produce
A completed Data → Decision form

One written pattern statement + one concrete instructional adjustment with a stated rationale — ready to implement without further preparation.

Why This Task Works
Application precedes generalization

Teachers practice the decision-making process with low-stakes data before applying it to their own students — reducing resistance and building a replicable habit.

Success Indicator
Specificity of the adjustment

A vague outcome ("I'll reteach it") signals the protocol wasn't used. A specific one ("I'll add a contrastive example at the error point") signals transfer.

Why This Works
  • Active engagement over passive listening. Teachers do the analysis themselves — they are not shown a framework and asked to believe it; they use it and feel whether it works.
  • Immediate application to teacher context. The Apply phase requires real data from their own class — the output is not a workshop artifact, it is a next-day lesson decision.
  • Built on Adult Learning Theory. Adults learn by doing, and learning sticks when it connects directly to problems they already face. Every phase is designed around relevance and immediacy.
Application Across CTE Programs
Content areas

The data analysis protocol is content-agnostic — it works with any formative check output: exit tickets, lab results, project drafts, or task samples from any CTE pathway.

Data sources

Works with any formative data source — no specialized tool required. A set of student responses on paper is sufficient to run the full protocol.

Instructional consistency

When run as a recurring team PD, this protocol builds a shared decision-making language across a department — making instructional adjustment a norm, not an exception.

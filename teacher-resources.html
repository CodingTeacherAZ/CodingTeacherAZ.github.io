Design Principles Across Resources
Principle 01
Immediate implementation

Every resource is ready to use in a single lesson without prior training, curriculum mapping, or tool setup. A teacher picks it up on Monday and uses it Tuesday.

Principle 02
Adaptable across CTE programs

Each tool is built around a transferable instructional structure — not subject-specific content. The scaffold, protocol, or framework flexes to any technical domain.

Principle 03
Structured for varied learners

Differentiation is embedded in how tasks are layered — not added on as a separate track. All students engage with the same core concept at the appropriate entry point.

How to Use These Resources
Step 01
Start with one resource

Select the tool that targets your most pressing instructional gap — don't implement more than one at a time.

→
Step 02
Implement in a single lesson

Run the protocol or scaffold as designed for one complete lesson cycle before making any modifications.

→
Step 03
Adjust based on response

Observe where students engage or stall, then adapt the structure to your specific student population and content.
